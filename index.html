Shiori栞

A visual novel engine designed to be written by language models: plain-text scripts, 2D and 3D stages, music in LMN, and a draft VNDB entry for every game.

Example games

The Lantern Keeper A short example from the spec: two sisters, a dark lighthouse, four endings (one unlocks), ADV and NVL, a 3D headland, LMN music.

Start

  • Read or give a model SHIORI-Spec.md, the full specification.
  • Add &dev=1 to a game URL for live reload, variables and jump-to-scene.
  • Command line, from this folder:
bin/shiori new games/my-game     # start a game from the template
bin/shiori check games/my-game   # errors and warnings with fixes
bin/shiori explore games/my-game # every route and ending
bin/shiori vndb games/my-game    # advisory VNDB read + draft entry
bin/shiori serve games/my-game   # play it in the browser
